# Race--Dash--Pro
**RACE DASH PRO** — это полностью кастомная цифровая приборная панель на базе Raspberry Pi, которая превосходит по функционалу коммерческие решения (Haltech, AEM, AIM) за **долю их стоимости**.  Проект с открытым исходным кодом — вы можете модифицировать интерфейс, добавлять функции и адаптировать под свои нужды.
