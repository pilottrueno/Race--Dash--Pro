## Описание

**RACE DASH PRO** — это полностью кастомная цифровая приборная панель на базе Raspberry Pi, которая превосходит по функционалу коммерческие решения (Haltech, AEM, AIM) за **долю их стоимости**.

Проект с открытым исходным кодом — вы можете модифицировать интерфейс, добавлять функции и адаптировать под свои нужды.

## Возможности

### 📊 Мониторинг в реальном времени
- Обороты двигателя (RPM) — до 10,000 об/мин
- Давление наддува — до 3.0 bar
- Температуры (ОЖ, масло, воздух, EGT, RPi)
- Давления (масло, топливо)
- Лямбда (λ) и AFR — широкополосный датчик
- Напряжение бортовой сети
- **Датчики детонации (2 канала)**
- **Положение дроссельной заслонки (TPS)**
- **Угол опережения зажигания (IGN)**

### 🗺️ Трекинг и GPS
- Запись трека в GeoJSON + CSV
- GPS координаты и скорость (SiRF III)
- Ускорения G-Force (акселерометр GY-521)
- Автоматическая запись только при движении

### 🔧 Системные функции
- Диагностика ошибок (CAN, Bluetooth, питание, перегрев)
- Автоочистка памяти при 90% заполнении
- Анализ логов через DeepSeek AI
- Wi-Fi подключение для передачи данных

### 🎮 Управление
- Свайп вправо — ручное управление актуаторами
- Свайп влево — графики в реальном времени
- Двойной клик — полноэкранный режим графика
- Цветовые темы (синяя, красная, жёлтая)

## Требования

### Минимальные
- Raspberry Pi 4 (2-8 ГБ) или Pi 3 B+
- Raspberry Pi OS Lite (64-bit)
- 7" сенсорный LCD (800x480)
- Блок питания 5В / 3А
- SD карта 16-64 ГБ (класс A2)

### Рекомендуемое оборудование
| Компонент | Модель | Назначение |
|:---|:---|:---|
| CAN шина | RS485 CAN HAT (MCP2515) | Чтение данных ЭБУ |
| GPS | GPS-500 SiRF III | Трекинг и скорость |
| Акселерометр | GY-521 (MPU6050) | Ускорения G-Force |
| RGB LED | WS2812 лента | Shift light |
